## 1. معمارية النظام

```
┌─────────────────┐         ┌──────────────────┐
│  تطبيق أندرويد   │  HTTPS  │   خادم (Backend)  │
│  (المندوب)       │◄───────►│  REST API + Auth  │
│  Kotlin + Room   │         │  Node.js/Express  │
│  osmdroid أوفلاين│         │  PostgreSQL       │
└─────────────────┘         └────────┬─────────┘
                                     │
                            ┌────────▼─────────┐
                            │  لوحة الإدارة     │
                            │  ويب (React RTL)  │
                            │  + استيراد KMZ    │
                            └──────────────────┘
```

## 2. التقنيات المختارة

| المكوّن | التقنية | السبب |
|---|---|---|
| تطبيق أندرويد | Kotlin + Android Studio | اللغة الرسمية لأندرويد |
| الخرائط في التطبيق | **osmdroid** (OpenStreetMap) | مجاني بالكامل، يدعم الأوفلاين، بدون مفاتيح API |
| قاعدة بيانات الجهاز | Room (SQLite) | تخزين المحلات والمناطق للعمل أوفلاين |
| الخادم | Node.js + Express | بسيط وسريع التطوير |
| قاعدة بيانات الخادم | **SQLite** (وحدة `node:sqlite` المدمجة) | البيانات صغيرة وقرائية غالباً (~3400 محل) والمزامنة بنمط نسخة كاملة — لا حاجة لخادم قاعدة بيانات منفصل، وصفر إدارة تشغيل. الانتقال إلى PostgreSQL لاحقاً سهل إن تطلب الأمر |
| المصادقة | JWT | جلسات طويلة على الجهاز |
| لوحة الإدارة | React + Leaflet (OpenStreetMap) | عربية RTL، خرائط مجانية، رسم مضلعات المناطق |
| استيراد KMZ | فك ضغط KMZ (ZIP) + تحليل KML (XML) | KMZ = ملف KML مضغوط |

## 3. استراتيجية الأوفلاين

1. **البيانات**: عند تسجيل الدخول الأول، يُنزَّل كامل المحلات والمناطق إلى Room.
   تحديث لاحق بطلب يدوي أو عند فتح التطبيق مع توفر إنترنت
   (مقارنة برقم إصدار بيانات `data_version` على الخادم — تنزيل كامل عند تغيره،
   فالبيانات صغيرة الحجم).
2. **الخرائط**: حزمة بلاطات (tiles) لمنطقة عمل الشركة بصيغة أرشيف SQLite
   تدعمه osmdroid، تُنزَّل مرة واحدة من الخادم (مقسّمة على مستويات تقريب مناسبة).
   بعدها لا حاجة لإنترنت نهائياً.

## 4. واجهات الخادم (API)

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/auth/login` | تسجيل دخول → JWT |
| GET | `/api/data/snapshot` | كل المناطق والمحلات + `data_version` |
| GET | `/api/tiles/package` | تنزيل حزمة الخرائط الأوفلاين |
| CRUD | `/api/admin/users` | إدارة المندوبين (إدارة فقط) |
| CRUD | `/api/admin/regions` | إدارة المناطق |
| CRUD | `/api/admin/stores` | إدارة المحلات |
| POST | `/api/admin/import/kmz` | رفع KMZ واستيراد المحتوى |

## 5. مخطط قاعدة البيانات

```sql
users   (id, name, username, password_hash, role, active)
regions (id, name, color, polygon jsonb)          -- polygon: [[lat,lng],...]
stores  (id, name, owner_name, phone, lat, lng, region_id, notes)
meta    (key, value)                              -- data_version, إلخ
```

## 6. استيراد KMZ — التدفق (مضبوط على بنية ملف الشركة الفعلي)

بنية الملف المعتمدة (`data/AFCs16.8.2026.kmz`):

```
Document
└── My Places
    ├── Transportation        → خطوط طرق — تُتجاهل
    └── AFC
        ├── Districts         → مضلعات حدود المناطق (54) + نقاط تسمية
        ├── Customers         → 62 مجلد منطقة ← 3293 محلاً (اسم + نقطة)
        └── Master            → مُتجاهَل (قرار العميل)
```

قواعد التحويل:
1. مجلدات `Customers` فقط → **مناطق**، والـ Placemarks ذات الـ Point داخلها → **محلات** (الاسم + الإحداثيات `lng,lat`).
2. الـ Placemarks ذات الـ Polygon تحت `Districts` → **حدود المناطق** بأسمائها.
3. مطابقة المنطقة بمضلعها بالاسم مع تطبيع بسيط (تجاهل الفروقات مثل الموكامبو/الموغامبو)؛ غير المطابَق يُعرض في المعاينة للحسم اليدوي.
4. معاينة النتائج في جدول (عدد محلات كل منطقة، حالات عدم المطابقة) قبل الحفظ.
5. رفع `data_version` ليعرف التطبيق أن عليه إعادة المزامنة.

> حقلا "اسم المالك" و"الهاتف" غير موجودين في الملف — يُستورَدان فارغين ويُستكملان من لوحة الإدارة
> أو باستيراد Excel لاحق إن وفرّته الشركة.

## 7. خطة التنفيذ (مراحل)

1. **M0 — الأساس**: إعداد المشاريع الثلاثة (أندرويد، خادم، لوحة إدارة) + قاعدة البيانات.
2. **M1 — الخادم**: المصادقة + CRUD + snapshot API.
3. **M2 — لوحة الإدارة**: إدارة مستخدمين/مناطق/محلات + استيراد KMZ.
4. **M3 — التطبيق**: خريطة أونلاين + تسجيل دخول + عرض محلات/مناطق + تفاصيل.
5. **M4 — الأوفلاين**: مزامنة Room + حزمة البلاطات + بحث/فلترة محلية.
6. **M5 — التلميع**: عربي RTL كامل، تجربة مستخدم، اختبار ميداني.
